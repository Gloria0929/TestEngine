## 1. 系统概述与整体布局

系统是一个一站式测试管理平台，包含：工作台、测试用例、测试计划、接口测试、缺陷管理、项目协作六大业务模块。

### 1.1 页面布局

系统采用"顶部导航 + 侧边菜单 + 内容区"布局（[DefaultLayout.vue](file:///Users/fuhao/Downloads/TestEngine/src/layouts/DefaultLayout.vue)）：

- **顶部栏**（[DefaultLayout.vue](file:///Users/fuhao/Downloads/TestEngine/src/layouts/DefaultLayout.vue)）
  - 品牌标识"TestEngine"（点击回到工作台首页）
  - 一级导航菜单（TopNavMenu）
  - 主题切换按钮：深色 / 浅色模式切换，切换过程带 0.3s 平滑过渡（见 [app.ts](file:///Users/fuhao/Downloads/TestEngine/src/app.ts)、[index.scss](file:///Users/fuhao/Downloads/TestEngine/src/styles/index.scss)）
- **侧边菜单**（[SidebarMenu.vue](file:///Users/fuhao/Downloads/TestEngine/src/layouts/components/SidebarMenu.vue)）：按 [menu.ts](file:///Users/fuhao/Downloads/TestEngine/src/config/menu.ts) 配置渲染，支持权限过滤，无权限的菜单项自动隐藏
- **顶部一级导航**（[TopNavMenu.vue](file:///Users/fuhao/Downloads/TestEngine/src/layouts/components/TopNavMenu.vue)）：测试计划、测试用例、缺陷管理、接口测试、项目协作；「测试计划」含二级导航：**计划列表 / 测试报告**，「测试用例」含二级导航：**用例列表 / 用例评审 / 用例回收站**，「接口测试」含二级导航：接口调试 / 接口定义 / 场景管理 / 接口报告，「项目协作」直接进入操作日志页
- **左侧模块目录**：测试计划、测试用例、缺陷管理、接口测试（定义/场景/报告，调试页除外）、项目协作五个模块的内容区左侧有与接口调试页"接口收藏"同风格的**目录侧边栏**（[ModuleFolderSidenav.vue](file:///Users/fuhao/Downloads/TestEngine/src/layouts/components/ModuleFolderSidenav.vue)），按文件夹管理业务记录：
  - 下方为**目录列表**：点击右上角 ➕ 新建文件夹；文件夹行悬浮显示重命名/删除图标；点击文件夹跳转列表页并按该目录过滤，展开后可直接点击其中的记录（如测试计划进入执行页、测试用例进入详情页、接口定义进入调试页、场景进入编辑页）
  - 末尾为**未分类**节点，展示未归入任何目录的记录；删除文件夹时其中记录自动移回未分类
  - 列表页同步支持：新建计划/用例弹窗可选**所在目录**，行操作含**移动**（移动到目录弹窗）
- **内容区**：各业务页面，默认进入 `/workstation/home`

### 1.2 通用交互约定

| 约定 | 说明 |
| --- | --- |
| 搜索/筛选栏 | 大多数列表页提供关键词 + 下拉筛选，配 **查询** / **重置** 按钮 |
| 分页 | 统一使用 `el-pagination`（layout: `sizes, prev, pager, next`），支持每页 10/20/50 条切换 |
| 表格 | 统一 `el-table`，列宽自适应（min-width），操作列固定右侧；表头与内容统一居中显示 |
| 参数输入区 | Params/Headers/Body 等键值对输入区，初始至少一行空行，末行有值时自动追加空行 |
| 回收站 | 用例删除后先入回收站，可恢复或彻底删除 |
| 状态标签 | 统一使用 `el-tag`（round 胶囊样式）展示状态与等级（草稿/待评审/就绪、P0–P3、HTTP 方法等） |
| 操作按钮样式 | 行内链接型按钮（编辑/删除/执行等）悬浮时无背景色，仅文字变色；顶栏横向菜单无外框线、无激活下划线，菜单项背景间留 4px 间隙 |

### 4.1 用例列表（`/test-case/list`）

代码：[testCase/list/index.vue](file:///Users/fuhao/Downloads/TestEngine/src/views/testCase/list/index.vue)

**顶部操作**：

| 按钮 | 说明 |
| --- | --- |
| 导入用例 | 打开导入弹窗，见下文 |
| 新建用例 | 打开用例编辑弹窗（CaseEditDialog），保存调用 `createCase` |

**导入用例弹窗**（[ImportDialog.vue](file:///Users/fuhao/Downloads/TestEngine/src/views/testCase/list/components/ImportDialog.vue)）：
1. 拖拽或点击选择 Excel 文件（.xlsx）；

3. 确认后逐条调用 `createCase` 批量创建；
4. 导入完成自动刷新列表。

**新建/编辑用例弹窗**（[CaseEditDialog.vue](file:///Users/fuhao/Downloads/TestEngine/src/views/testCase/list/components/CaseEditDialog.vue)）：

- 步骤表格支持"添加步骤"，每行为多行文本框（自适应 1-4 行，占位"请输入步骤"/"请输入预期"），末尾保留一个空占位行，保存时自动过滤空行；
- 点击 **保存**：校验表单 → 新建走 `createCase`，编辑走 `updateCase`。

代码：[testCase/review/index.vue](file:///Users/fuhao/Downloads/TestEngine/src/views/testCase/review/index.vue)

| 按钮/操作 | 说明 |

| 编辑（行内） | 跳转评审详情页（`/test-case/review/detail/:id`，[detail.vue](file:///Users/fuhao/Downloads/TestEngine/src/views/testCase/review/detail.vue)） |

**用例评审页**（`/test-case/review/detail/:id/case/:caseId`，[caseReview.vue](file:///Users/fuhao/Downloads/TestEngine/src/views/testCase/review/caseReview.vue)）：参考执行用例页布局——面包屑 + 用例标题与评审结果 tag，"基本信息 / 详情" 两个 Tab（基本信息含测试点、等级、标签、评审目的、备注；详情含前置条件、步骤描述表格、备注）；底部操作栏选择 **通过 / 不通过**、填写评审意见，支持 **自动下一条**，**提交评审** 调用 `submitReviewResult` 后返回详情页；全部用例评审完毕后评审整体状态自动更新为"通过"或"驳回"。

**评审流程**：新建评审（指定评审人 + 关联用例）→ 列表点 **编辑** 进入评审详情 → 逐条点 **评审** 进入用例评审页给出通过/不通过 + 意见 → 全部提交后评审状态更新为"通过"或"驳回"。

| 重命名 / 删除 | 文件夹行与接口行悬浮时显示操作图标（删除文件夹会连带删除其中接口，有确认） |

**请求行**：

- 请求方法下拉（GET/POST/PUT/DELETE 等）+ URL 输入框；
- **发送**：`buildRequest` 组装参数/头/体/认证 → 调用 `executeRequest` → 展示响应；
- **保存**：将当前请求保存到左侧收藏夹；
- **清空**：重置请求与响应区。

**请求配置 Tab**：

| Tab | 说明 |
| --- | --- |
| Params | 查询参数键值对表格（参数名/值/描述三列），末行有值自动追加空行 |
| Authorization | 认证配置（如 Bearer Token 等） |
| Headers | 请求头键值对表格，规则同 Params |
| Body | 请求体编辑（[BodyEditor.vue](file:///Users/fuhao/Downloads/TestEngine/src/views/apiTest/debug/components/BodyEditor.vue)），类型可切换：`none / form-data / x-www-form-urlencoded / raw`；键值对类型为三列表格并自动补空行，raw 为文本输入（JSON 等） |

**响应区**：展示响应状态码、耗时、响应头与响应体，出错时展示错误信息。

## 8. 典型业务流程总览

### 8.1 功能用例全流程

```
新建用例（列表页/导入 Excel）
   ↓
提交评审（新建评审 → 评审人逐条 通过/不通过 + 意见 → 提交）
   ↓ 评审通过
创建测试计划 → 关联用例
   ↓
执行用例（逐步骤记录实际结果 → 成功/阻塞/失败 → 支持自动下一条、添加缺陷）
   ↓
生成报告（进度/通过率/失败分布 → 导出 HTML/Excel、复制分享链接、失败转缺陷）
   ↓
缺陷跟踪（新建/编辑/关闭）
```

### 8.2 接口测试流程

```
接口定义（手工新建 或 粘贴 Swagger/Postman/HAR 导入）
   ↓
接口调试（选方法与 URL → 配 Params/Headers/Body/Authorization → 发送 → 查看响应）
   ↓
场景编排（添加步骤 → 拖拽排序 → 配置场景参数 → 保存）
   ↓
场景执行 → 查看接口报告（通过率、详情，可删除）
```

### 8.3 用例删除与恢复

```
列表页删除用例 → 进入用例回收站
   → 恢复：回到用例列表
   → 彻底删除：二次确认后永久删除
```
